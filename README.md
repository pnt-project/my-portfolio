# วิธีติดตั้ง: ดึงราคาอัตโนมัติทุกวัน + เปิดใช้งานออนไลน์จากที่ไหนก็ได้

ไฟล์ชุดนี้ใช้ **GitHub** (ฟรี) ทำ 2 อย่าง:
1. **GitHub Actions** รันสคริปต์ดึงราคาหุ้น/Benchmark ให้อัตโนมัติทุกวันทำการ เวลา **07:00 น. ไทย** (จุดเดียว ครอบคลุมทั้งตลาดหุ้นไทยที่ปิดไปแล้วตั้งแต่เย็นวันก่อน และตลาดหุ้นสหรัฐฯ ที่เพิ่งปิดตอนดึก) แล้วบันทึกผลลง `prices.json`
2. **GitHub Pages** โฮสต์หน้าเว็บให้มี URL จริง เปิดจากมือถือ/คอมเครื่องไหนก็ได้

ข้อมูลพอร์ต (ธุรกรรม, เงินปันผล ฯลฯ) ที่คุณกรอกในหน้าเว็บ **ยังคงอยู่แค่ในเบราว์เซอร์ของคุณเท่านั้น** ไม่ถูกส่งขึ้น GitHub — สิ่งที่ไปอยู่บน GitHub มีแค่ราคาหุ้น/ดัชนีที่ดึงมาอัตโนมัติ (`prices.json`) ซึ่งไม่ใช่ข้อมูลส่วนตัว

## ขั้นตอน

1. **สร้างบัญชี GitHub** (ถ้ายังไม่มี) ที่ https://github.com/signup — ฟรี
2. **สร้าง repository ใหม่** (ปุ่ม "New repository") ตั้งชื่ออะไรก็ได้ เช่น `my-portfolio-tracker` เลือก **Public** (จำเป็นสำหรับ GitHub Pages ฟรี)
3. **อัปโหลดไฟล์ทั้งหมด** ในแพ็กเกจนี้ขึ้น repo (ลากไฟล์ทั้งหมดวางในหน้า GitHub หรือใช้ `git push` ถ้าถนัด) ให้ครบทุกไฟล์รวมโฟลเดอร์ `.github/` และ `scripts/` ด้วย
4. **แก้ไข `symbols.json`** ให้ตรงกับหุ้นและ Benchmark ที่คุณติดตามจริง:
   ```json
   {
     "stocks": ["PTT", "AOT", "KBANK"],
     "benchmarks": [
       { "name": "SET Index", "symbol": "^SET.BK" },
       { "name": "Gold", "symbol": "GC=F" }
     ]
   }
   ```
   - `stocks` ใส่แค่รหัสหุ้น (ระบบจะเติม `.BK` ให้เอง)
   - `benchmarks` ใส่สัญลักษณ์ตามรูปแบบ Yahoo Finance (หาได้จากค้นชื่อสินทรัพย์ใน finance.yahoo.com แล้วดูสัญลักษณ์ในหน้านั้น)
5. **เปิดใช้งาน GitHub Pages**: ไปที่ repo → Settings → Pages → Source เลือก "Deploy from a branch" → Branch เลือก `main` และโฟลเดอร์ `/ (root)` → Save
   - รอ 1-2 นาที จะได้ URL ประมาณ `https://<username>.github.io/<repo-name>/investment-tracker.html`
   - เปิด URL นี้จากมือถือหรือเครื่องไหนก็ได้ ไม่ต้องมีไฟล์ในเครื่อง
6. **ตรวจสอบว่า GitHub Actions ทำงาน**: ไปแท็บ "Actions" ของ repo → ควรเห็น workflow "Update Prices" — กด "Run workflow" เพื่อทดสอบรันด้วยตนเองครั้งแรก (ไม่ต้องรอถึงเวลา 07:00) ถ้าสำเร็จจะมีไฟล์ `prices.json` ถูกสร้าง/อัปเดตใน repo อัตโนมัติ

จากนั้นทุกวันทำการเวลา 07:00 น. (เขตเวลาไทย) ระบบจะดึงราคาล่าสุดของทั้งตลาดไทยและตลาดสหรัฐฯ ให้เองโดยไม่ต้องเปิดเว็บทิ้งไว้ — พอคุณเข้าเว็บครั้งถัดไป จะเห็นแถบแจ้งเตือนด้านบนสุดของหน้า ให้กด **"ใช้ราคานี้อัปเดตพอร์ต"** หรือ **"เพิ่ม Snapshot วันนี้จากข้อมูลนี้"** ได้เลย

## ข้อจำกัดที่ควรรู้

- เวลารันจริงของ GitHub Actions อาจคลาดเคลื่อนจากเวลาที่ตั้งไว้ไม่กี่นาทีถึงสิบกว่านาที (ปกติของบริการฟรี)
- ราคาที่ได้มาจาก Yahoo Finance ผ่านไลบรารี `yfinance` ซึ่งไม่ใช่ทางการ อาจมีดีเลย์หรือคลาดเคลื่อนได้ ควรตรวจสอบกับแหล่งทางการก่อนใช้ตัดสินใจลงทุนจริง
- หุ้นไทยบางตัวอาจไม่มีอยู่ใน Yahoo Finance หรือสัญลักษณ์ไม่ตรง ต้องลองปรับเองใน `symbols.json`
- repo ต้องเป็น Public ราคาหุ้น/ดัชนีใน `prices.json` จะเป็นข้อมูลสาธารณะที่ใครก็เห็นได้ (แต่ไม่ใช่ข้อมูลพอร์ตส่วนตัวของคุณ)

## ส่วนที่ 2 (ไม่บังคับ): Sync ข้อมูลข้ามเครื่อง + Auto Snapshot จริงๆ โดยไม่ต้องเปิดเว็บ

ส่วนที่ 1 ด้านบนทำให้ราคาหุ้นอัปเดตอัตโนมัติ และเว็บเปิดได้จากทุกที่ แต่ **ข้อมูลธุรกรรม/พอร์ตของคุณยังอยู่แค่ในเบราว์เซอร์เครื่องเดียว** และ **Snapshot ยังต้องกดปุ่มเองอยู่** — ถ้าอยากให้ข้อมูลตามไปทุกเครื่อง และ NAV ถูกคำนวณให้เองทุกวันโดยไม่ต้องเปิดเว็บเลย ต้องเพิ่มฐานข้อมูลจริง (Firebase, ฟรี) ตามนี้:

### 1. สร้างโปรเจกต์ Firebase
1. เข้า https://console.firebase.google.com → "Add project" → ตั้งชื่ออะไรก็ได้ → สร้างเสร็จ
2. เมนูซ้าย "Build" → **Firestore Database** → "Create database" → เลือกโหมดไหนก็ได้ (จะตั้งกฎเองทีหลัง) → เลือก region ที่ใกล้ที่สุด (เช่น asia-southeast1) → เสร็จ
3. เมนูซ้าย "Build" → **Authentication** → "Get started" → แท็บ "Sign-in method" → เปิดใช้ **Email/Password** → Save

### 2. เอา config มาใส่ในเว็บ
1. คลิกไอคอนเฟือง (⚙️) มุมบนซ้าย → **Project settings**
2. เลื่อนลงหา "Your apps" → กดไอคอน **</>=** (Web) → ตั้งชื่อแอปอะไรก็ได้ → "Register app"
3. จะเห็นโค้ด `firebaseConfig = {...}` — copy ค่าทั้งหมดในนั้น
4. เปิดไฟล์ `investment-tracker.html` ด้วยโปรแกรมข้อความ หาคำว่า `var firebaseConfig = {` แล้ว**แทนที่ค่า placeholder ทั้งหมดด้วยค่าจริงที่ copy มา**
5. อัปโหลดไฟล์ที่แก้แล้วขึ้น GitHub แทนไฟล์เดิม (commit ทับ) รอ GitHub Pages deploy ใหม่ (1-2 นาที)

### 3. ตั้งกฎความปลอดภัยของ Firestore
1. กลับไปที่ Firestore Database → แท็บ **Rules**
2. แทนที่เนื้อหาทั้งหมดด้วย:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /portfolios/{uid} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }
   ```
3. กด "Publish" — กฎนี้ทำให้แต่ละคนเห็น/แก้ได้แค่ข้อมูลของตัวเองเท่านั้น

### 4. สมัครบัญชีในหน้าเว็บ
1. เปิดเว็บที่ deploy ไว้ (URL จาก GitHub Pages)
2. จะเห็นกล่อง **"☁️ บัญชีสำหรับ Sync ข้ามเครื่อง"** ด้านบนสุด — กรอกอีเมล+รหัสผ่าน กด **"สมัครสมาชิก"**
3. เข้าสู่ระบบสำเร็จจะเห็น **UID** ของคุณแสดงอยู่ — copy เก็บไว้
4. ทดสอบ: เปิดเว็บเดียวกันจากมือถือหรือเครื่องอื่น เข้าสู่ระบบด้วยอีเมล/รหัสผ่านเดียวกัน → ข้อมูลควรตามมาให้ (ถ้ายังไม่มีข้อมูลก็จะว่างเหมือนกันทั้งสองเครื่อง แล้วพอกรอกที่เครื่องไหน อีกเครื่องจะเห็นตามเมื่อรีเฟรช)

### 5. เปิดใช้งาน Auto Snapshot (ไม่ต้องเปิดเว็บเลย)
1. Firebase Console → ⚙️ Project settings → แท็บ **Service accounts** → "Generate new private key" → ยืนยัน จะได้ไฟล์ .json ดาวน์โหลดมา (เก็บเป็นความลับ ห้ามอัปขึ้น GitHub โดยตรง)
2. เปิดไฟล์ .json นั้นด้วยโปรแกรมข้อความ copy เนื้อหาทั้งหมด
3. ไปที่ repo บน GitHub → **Settings** → **Secrets and variables** → **Actions** → "New repository secret"
   - ชื่อ: `FIREBASE_SERVICE_ACCOUNT` ค่า: วางเนื้อหาไฟล์ .json ทั้งหมด → Add secret
4. เพิ่ม secret อีกตัว ชื่อ: `FIREBASE_UID` ค่า: UID ที่ copy ไว้จากขั้นตอนที่ 4 → Add secret
5. ไปแท็บ **Actions** → เลือก workflow "Update Prices" → "Run workflow" ทดสอบรันเอง
6. เช็คผล: Firebase Console → Firestore Database → Data → `portfolios` → เอกสารที่มี UID ของคุณ → ควรเห็น field `snapshots` มีรายการใหม่ของวันนี้เพิ่มเข้ามา

จากนี้ทุกวันทำการเวลา **07:00 น. ไทย** ระบบจะ:
1. อ่านธุรกรรมทั้งหมดจาก Firestore
2. คำนวณจำนวนหุ้นไทยคงเหลือ
3. ดึงราคาปิดล่าสุดของหุ้นไทย + Benchmark ทุกตัว (รวมฝั่งสหรัฐฯ) จาก Yahoo Finance — ณ เวลานี้ทั้งตลาดไทย (ปิดตั้งแต่เย็นวันก่อน) และตลาดสหรัฐฯ (เพิ่งปิดตอนดึก) ปิดครบแล้วทั้งคู่ จึงได้ราคาปิดจริงของทั้งสองตลาดในการรันครั้งเดียว
4. คำนวณมูลค่าพอร์ตรวม + ค่า Benchmark
5. เพิ่ม Snapshot ของวันนั้นเข้า Firestore ให้เองอัตโนมัติ **โดยไม่ต้องเปิดเว็บเลย**

เปิดเว็บจากเครื่องไหนก็ได้ทุกเมื่อ ข้อมูลและ Snapshot จะรออยู่ครบแล้ว

### ข้อจำกัดของส่วนนี้
- ต้องสมัครบัญชี Firebase (ฟรี ไม่ต้องผูกบัตรเครดิตสำหรับ tier ฟรี) และทำตามขั้นตอนเองครั้งแรก
- ไฟล์ service account (.json) คือกุญแจเข้าถึงฐานข้อมูลทั้งหมด **ห้ามอัปขึ้น GitHub แบบไฟล์ปกติเด็ดขาด** ใส่เป็น GitHub Secret เท่านั้นตามขั้นตอนข้างบน
- Auto Snapshot จะคำนวณจากธุรกรรมที่บันทึกไว้ใน Firestore ล่าสุด ถ้ายังไม่เคย sign in บนเว็บเลยสักครั้ง จะยังไม่มีเอกสารให้ script อ่าน (ต้อง sign in อย่างน้อย 1 ครั้งก่อน)
- ระบบนี้เป็น personal-use scale ไม่ได้ออกแบบสำหรับผู้ใช้จำนวนมาก แต่เพียงพอสำหรับติดตามพอร์ตส่วนตัว
- Auto Snapshot จะรันให้ **ทุกพอร์ต** ที่มีอยู่ในบัญชีของคุณโดยอัตโนมัติ (ไม่ต้องเลือก)

## ส่วนที่ 3: ฟีเจอร์เพิ่มเติม

### หลายพอร์ต (Multi-portfolio)
กล่อง **"📁 พอร์ตการลงทุน"** ด้านบนสุดของเว็บ:
- เลือกสลับพอร์ตจาก dropdown
- **"+ พอร์ตใหม่"** สร้างพอร์ตแยกต่างหาก (ธุรกรรม, Benchmark, Snapshot แยกกันคนละชุดสมบูรณ์)
- **"✏️ เปลี่ยนชื่อ"** แก้ชื่อพอร์ตที่เลือกอยู่
- **"🗑️ ลบพอร์ตนี้"** ลบพอร์ตที่เลือกอยู่ (ต้องเหลืออย่างน้อย 1 พอร์ตเสมอ)

ถ้าตั้งค่า Firebase sync ไว้ ทุกพอร์ตจะ sync ข้ามเครื่องพร้อมกันทั้งหมด และ Auto Snapshot จะรันให้ทุกพอร์ตอัตโนมัติทุกวัน

### ล็อกด้วย PIN
ปุ่ม **"🔒 ตั้ง/เปลี่ยน PIN"** ที่มุมขวาบน — ตั้งรหัส 4-8 หลัก พอตั้งแล้วทุกครั้งที่เปิดเว็บ (หรือกด "🔒 ล็อกตอนนี้") จะต้องใส่ PIN ก่อนถึงจะเห็นข้อมูล

⚠️ **สำคัญ:** นี่คือ**การล็อกหน้าจอแบบพื้นฐาน**ป้องกันคนเผลอเปิดดูมือถือ/คอมของคุณเฉยๆ **ไม่ใช่การเข้ารหัสข้อมูลระดับสูง** เพราะ:
- ตัวเช็ค PIN ทำงานอยู่ใน JavaScript ฝั่งเบราว์เซอร์ ซึ่งใครก็เปิดดู source code หรือแก้ไข localStorage ผ่าน Developer Tools เพื่อข้ามได้ถ้าตั้งใจจริง
- ข้อมูลพอร์ตจริงไม่ได้ถูกเข้ารหัสด้วย PIN นี้ (ยังเก็บเป็น JSON ปกติใน localStorage/Firestore)
- เหมาะสำหรับกันคนใกล้ตัวเผลอเห็นเฉยๆ ไม่เหมาะเป็นเกราะป้องกันข้อมูลสำคัญระดับธนาคาร

PIN นี้ผูกกับ**เบราว์เซอร์/เครื่องนั้นๆ เท่านั้น** ไม่ sync ข้ามเครื่อง (ต่างจากบัญชีอีเมล Firebase) — ถ้าลืม PIN ให้เปิด Developer Tools ของเบราว์เซอร์ รัน `localStorage.removeItem('trackerPinHash')` แล้วรีเฟรชหน้า

### โน้ตในประวัติธุรกรรม
ในฟอร์ม "บันทึกธุรกรรม" มีช่อง **"โน้ต (ไม่บังคับ)"** ให้พิมพ์เหตุผลหรือบันทึกอะไรก็ได้ เช่น "ซื้อเพิ่มเพราะราคาย่อ" — จะแสดงในตารางประวัติธุรกรรมคอลัมน์ "โน้ต" และถูก sync/export ไปพร้อมข้อมูลอื่นๆ ทั้งหมด
